# 老白の日记：全功能视觉首稿

实际生成：60/60 个设计单元，45个主视图与15组状态。

打开 index.html 逐页看图、作图依据和已识别待修正项；screens 为45张独立分图，boards 为原图和修订图，旧版保留作对照。

以 manifest.json 的 image/board 路径为当前版本，不要把旧版原图当定稿。

图册由用户指定的 Quya Responses API 生成，请求模型 gpt-image-2.5-sunburst；prompts 保存出图提示词，不含密钥。图片实际尺寸记录在 image-integrity.json。

图片已生成不等于功能验收通过。须逐页检查必备字段、数字、枚举、空白状态和模型可能加入的额外控件。Figma 尚未开始，App 未修改。分图裁自三联原图，原图一并保留。这些不是小米14实测截图；图片比例、字体和系统栏像素不能直接当作安卓布局规范。
